# 🤝 Contributing to Spotlight

Thank you for your interest in contributing to **Spotlight**! We welcome community contributions, bug fixes, feature enhancements, and documentation improvements.

## 🚀 How to Contribute

1. **Fork the Repository**:
   - Create your own fork of the repository on GitHub.

2. **Clone & Set Up Locally**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/SpotLight.git
   cd SpotLight
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Code Standards & Validation**:
   - Ensure clean code formatting.
   - Run oxlint in frontend: `npm run lint` inside `frontend/`.
   - Test production build: `npm run build` inside `frontend/`.

5. **Commit & Push**:
   ```bash
   git add .
   git commit -m "feat: description of your changes"
   git push origin feature/your-feature-name
   ```

6. **Submit a Pull Request**:
   - Open a Pull Request (PR) against the `main` branch with a clear summary of your enhancements.

Thank you for building Spotlight together! 🌟
